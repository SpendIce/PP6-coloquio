# Coloquio TP Integrador — PP6

Material de estudio para el coloquio del TP Integrador de Paradigmas de Programación VI (acortador de enlaces, [SpendIce/PP6-TPIntegrador](https://github.com/SpendIce/PP6-TPIntegrador)).

**Verlo en el navegador:** https://spendice.github.io/PP6-coloquio/

- `index.html`: inicio y plan.
- `lessons/`: siete lecciones con quiz, ejercicios y práctica oral.
- `reference/mapa-del-codigo.html`: cada pieza del código con su capa y su origen (consigna / Q1–Q26 / decisión técnica).

Sitio estático, sin build: GitHub Pages lo sirve tal cual desde `main`.
